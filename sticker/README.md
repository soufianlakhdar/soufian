# "No worries, I'm not mad" sticker 😁🔪

An ordinary yellow emoji man with an innocent smile and a side-eye, hiding a kitchen knife (tiny red smear) behind his back.

| File | Use |
| --- | --- |
| `innocent-knife-whatsapp-sticker.webp` | WhatsApp sticker: 512 × 512, transparent, white border, ~31 KB |
| `innocent-knife-emoji-outline.png` | 1024 × 1024 transparent PNG with white sticker border (reads well on dark chats) |
| `innocent-knife-emoji.png` | 1024 × 1024 transparent PNG, no border |
| `innocent-knife-emoji.svg` | Editable vector source |

## Send it as a real sticker on WhatsApp

1. Save the `.webp` (or a PNG) to your phone or computer.
2. In any chat, open the sticker panel and tap **Create** (WhatsApp Web/Desktop: emoji button → Stickers → Create).
3. Pick the saved image and send it.
4. Long-press the sent sticker → **Add to Favorites** to reuse it in one tap.

Pasting the PNG straight into a chat also works, but it arrives as a photo instead of a sticker.
